Dev khai mã

URL máy này:

Claude Code (VS Code) — Claude

  1. Cài extension Claude Code trong VS Code.
  2. Ctrl+Shift+P → Preferences: Open User Settings (JSON).
  3. Dán JSON dưới đây, thay sk-team-… bằng mã nội bộ. Không thêm /v1.
  4. Reload Window rồi hỏi như bình thường.
